🔐 실제 네이버 계정으로 로그인 (권장)
아래 버튼을 누르면 네이버 로그인 창이 열립니다. 로그인 후 카페 글쓰기 권한에 동의하시면 백엔드 서버가 Access Token을 안전하게 저장하고 실제 게시에 사용합니다.
※ 이 방법을 쓰려면 먼저 server 폴더 안의 시작.bat을 실행해 백엔드 서버를 켜두셔야 합니다.
🧪 수동/테스트 입력 (선택 — 실제 게시에는 사용되지 않습니다)
💡 네이버 개발자 센터(developers.naver.com)에서 발급받은 애플리케이션 정보를 아래에 입력해두면 참고용으로 저장됩니다.
보안을 위해 인증 정보는 코드에 하드코딩되지 않으며, 사용자의 로컬 브라우저 보안 스토리지에만 저장됩니다. 실제 게시 가능 여부는 위쪽 "실제 로그인" 연결 상태로만 결정됩니다.
